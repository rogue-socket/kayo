# Color Preferences

## Summary
Yash's favorite single color is black, with a preferred two-color combo of black and neon yellow.

For a three-color combination, the strongest preference is black, white, and red. This is a clear style preference that can guide aesthetic choices in design, branding, themes, and visual direction.

## Key Ideas
- Favorite single color: black
- Preferred two-color combo: black + neon yellow
- Best three-color combo: black + white + red

## Insights & Claims
- Black is the anchor color across all preferred combinations
- High-contrast accents (neon yellow, white, red) are preferred over muted palettes

## Actionable Takeaways
- Use black as the default base color for visual concepts
- Use neon yellow as the first accent option when bold contrast is needed
- Use black, white, and red for strong three-tone themes

## Why This Matters
- These preferences make visual decisions faster and more consistent across projects and personal branding.

## Applications
- UI theme and dashboard styling
- Brand palettes for personal projects
- Presentation and poster color direction
